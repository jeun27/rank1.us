## v3: Supabase-style dark (founder, 2026-11-06: "more like supabase ui/ux and not like the beige background"; "supabase ui components look a lot like profound ai's components")

Files: `landing-v3.html`, `dashboard-v3.html` (append `#light` for O2, `#competitors` for the second view), `team-workspace-v3.html` (`#switcher`, `#table`, `#analytics`, `#clients`). Screens: `shots/v3/`. Reference captures, public pages only, never logged in: `ref/sbd-*.png` (dark), `ref/sb-*.png` (light), `ref/supabase-*.json`.

What Supabase and Profound share, and what v3 adopts:
- A near-black neutral stack (Supabase's page is oklch 0.19, panel 0.215).
- 1px hairlines instead of shadows.
- Inter UI text at 12-14px, weight 450-500.
- A three-tier text scale (95% / 80% / 68% lightness).
- 6px radii and small, dense controls (26-32px).
- A left rail with grouped items.
- A breadcrumb top bar with switchers.
- Sticky-header tables.
- One accent glow on the hero.

Not taken: Supabase's green, logo, illustrations and copy.

### Earlier decisions restated under v3

- D14: means the dark rail for **every** surface (/app, /team, the landing demo). In O2 light the rail stays dark (#0B0C0E).
- D20: the /team client switcher is now in the top-bar breadcrumb, not the sidebar head. It is still a listbox (arrow keys, Enter, Escape) with clients only and a last row "Clients" opening the invites tab, plus the no-JS GET fallback.
- D21: the Context panel stays on the right, toggled by "Context". Nothing calls a model.
- D22: the Competitors table view keeps 4 engine numbers per row (an exception that still needs sign-off). The chart view keeps ≤3.
- D24: the feedback is kept (press, hover arrow, circled arrow dropped for a plain arrow). The pill shape is replaced by D35.
- D25-D31 (v2 motion, browser surfaces, no eyebrows, reduced motion) all still apply. Selection, caret and accent colours now come from Jelly blue.
