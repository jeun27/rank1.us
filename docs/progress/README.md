# Progress notes

Feature PRs add a note file docs/progress/<date>-<slug>.md (and docs/handoff/<date>-<slug>.md for
interface notes) instead of editing PROGRESS.md/HANDOFF.md; the lead folds them in.

One file per PR, named by the date and the PR's branch slug, for example
`2026-11-06-gas-ready.md`. Write the same content the PR would have added to PROGRESS.md or
HANDOFF.md. Folded files are removed from these folders.
